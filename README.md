## 📱 What is Crew Bites?

**Crew Bites** is a mobile app that eliminates the chaos of group food ordering. No more "who ordered what?" confusion — everyone in your crew knows exactly what they're eating and how much they owe.

Perfect for:
- 🍽️ Family dinners where everyone orders different things
- 👥 Friend hangouts at restaurants
- 🏢 Office lunch orders
- 🎉 Group events and celebrations

---

## ✨ Key Features

### 🧑‍🤝‍🧑 Group Management
- Add friends with custom names and avatars
- Favorite friends to keep them for every order
- Swipe gestures for quick actions (favorite ⭐ / delete 🗑️)
- Fun emoji and color-coded avatars

### 🍔 Food Ordering
- Assign food items to specific friends
- Track quantities per person
- Add notes to food items (e.g., "no onions")
- Restaurant bundles for quick ordering (pre-saved menus)

### 💰 Smart Bill Splitting
- **Automatic tip calculation** — Fixed amount or percentage
- **Delivery fee splitting** — Evenly or by order value
- **Tax & service charges** — Configurable percentages
- **Per-person totals** — Each person sees exactly what they owe
- **Rounding options** — Round to whole numbers for cleaner splits

### 📊 Price Tracking
- Toggle prices on/off based on your needs
- Set prices per food item
- See order totals and individual breakdowns
- Track food subtotals before extras

### 📜 Order History
- Save last 3 orders for quick reference
- Restore previous orders with one tap
- Reuse same crew or full order from history

### 🌍 Bilingual Support
- **English** + **Arabic** (Egyptian dialect)
- Automatic language switching
- RTL support for Arabic users

### 🎨 Customization
- **6 Color Themes**: Coral, Ocean, Grape, Mint, Mango, Neon
- **Dark/Light mode** with system auto-switching
- **5 Currency options**: USD ($), SAR (﷼), QAR (ر.ق), EUR (€), EGP (ج.م)
- **4 Friend icon styles**: Emoji, Roman numeral, First letter, First two letters

### 🔒 Privacy First
- **100% Offline** — No internet required
- **No account needed** — Just open and use
- **No ads, no tracking** — Your data stays on your phone
- **No cloud sync** — Complete privacy for your orders

### 📤 Sharing Options
- Copy order summary as text
- Share via messaging apps
- Share an offline QR code containing the order
- Create reusable bundles from any order

### ✅ Collection Tracking
- Mark each person's share as paid
- Favorite recurring orders for quick reuse
- Filter history to show favorite orders

## 🚀 Getting Started

### Prerequisites
- Flutter SDK 3.0 or higher
- Dart SDK 3.0 or higher
- Android Studio / VS Code
- iOS Simulator / Android Emulator

### Installation

```bash
# Clone the repository
git clone https://github.com/Juma1988/crew_bites.git

# Navigate to project directory
cd crew_bites

# Install dependencies
flutter pub get

# Run the app
flutter run
```
